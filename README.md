# NovaX
Independent trading-platform UI prototype built from scratch using the user's supplied visual references.

## Preview
Static HTML/CSS/JS. No Deriv dependency, no broker integration, no real-money trading, and no live market feed are connected. Chart, percentages and wallet are illustrative demo UI only.

## Deploy
Publish the repository root as a Render Static Site (no build command; publish path `.`).

## Next production steps
- Choose and integrate an independent, licensed market-data provider.
- Implement secure authentication, wallet ledger and server-side trade execution.
- Integrate regulated payment providers with signed webhooks and reconciliation.
- Add KYC/AML, jurisdiction checks, risk disclosures, responsible-trading controls, audit logs and security review.
